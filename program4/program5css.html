CSS (Cascading Style Sheets) is a cornerstone technology of the World Wide Web, used alongside HTML and JavaScript to control the presentation, formatting, and layout of web pages. While HTML provides the structural foundation of a page, CSS applies the visual design—such as colors, fonts, spacing, and layouts.
